# 0. Подготовка (делается один раз)

sudo apt install git -y — установка Git.
git config --global user.name "Твой username" — настройка имени.
git config --global user.email "твой@email.com" — настройка почты.
git config --global credential.helper store — сохранить логин/токен, чтобы не вводить каждый раз.
git clone https://github.com/ТВОЙ_USERNAME/имя-репозитория.git — скачать репозиторий на компьютер.

# 1. Проверка состояния (перед любым действием)

git status
Что делает: Показывает, какие файлы были изменены, какие готовы к отправке, а какие Git ещё не видит.
Красный цвет: Изменения есть, но они не готовы к фиксации.
Зелёный цвет: Изменения готовы к фиксации (после git add).

# 2. Подготовка файлов (Индексация)

git add имя_файла — подготовить конкретный файл.
git add . — подготовить все изменённые файлы сразу (точка в конце обязательна).
Что делает: Говорит Git: «Следи за этими изменениями, я хочу их сохранить».

# 3. Фиксация изменений (Commit)

git commit -m "Краткое описание того, что я сделал"
Что делает: Создаёт «снимок» твоего проекта с комментарием. Это локальная операция, на GitHub пока ничего не ушло.
Совет: Пиши осмысленные комментарии. Например: git commit -m "Добавил команды для навигации".

# 4. Отправка на GitHub (Push)

git push origin main
Что делает: Отправляет твои зафиксированные изменения на удалённый сервер (GitHub).
Если попросит пароль: Вводи свой Personal Access Token (тот, что начинается с ghp_...).

## Дополнительные полезные команды:

git log — посмотреть историю коммитов.
git pull origin main — скачать изменения с GitHub, если ты менял файлы через браузер.
git diff — показать, какие именно строки ты изменил (до git add).
